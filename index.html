Ảnh sản phẩm

Để ảnh trong 1 thư mục (cùng chỗ với file này, hoặc link web/Drive công khai). App sẽ tự ghép: thư mục ảnh + tên mã. Mã nào tên file khác thì dán "Link ảnh riêng" cho mã đó.
Muốn thêm ảnh phụ (ảnh 2, 3...) mà không cần dán link: đặt tên file thêm -2, -3... vào cuối, ví dụ mã "BO 80D26L" thì ảnh phụ tên bo-80d26l-2.jpg.
